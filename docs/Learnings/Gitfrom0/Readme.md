CloudOps AI Platform is a single, ambitious educational system that combines cloud operations and AI assistance. You build APIs and workers that deploy containerized applications to Kubernetes, monitor them with Prometheus/Grafana, centralize logs with Fluent Bit/Loki, automate delivery with GitHub Actions and Helm (optionally Argo CD), and add ChatGPT-style assistants that use RAG and MCP tools to troubleshoot safely. Think of it as your personal mix of Kubernetes Dashboard (control), Datadog/Grafana (observe), GitHub Actions (deliver), ChatGPT (assist), and Argo CD (GitOps).
